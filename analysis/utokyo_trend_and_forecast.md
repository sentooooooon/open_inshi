# 1. CS 専門科目の傾向

## 1.1 分野配置

### 読み取れる構造

1. **形式言語・オートマトンは毎年必ず1題**。しかも **fy2022 以降は4年連続で問題1**に固定されている。
2. **計算機アーキテクチャ／論理回路も毎年必ず1題**。
3. **アルゴリズム・離散数学も毎年必ず1題**。
4. **OS は隔年寄り**。fy2022・fy2024・fy2025 に出題、fy2020・fy2023 は非出題。OS が無い年はその枠に**プログラム意味論**（fy2023）や**機械学習**（fy2020）が入る。
5. 4分野の「並び順」は固定されていないが、fy2024・fy2025 は
   `形式言語 → (OS または アーキ) → (アーキ または OS) → アルゴリズム`
   という同型配置。

## 1.2 形式言語問題の出題テンプレート

fy2020・fy2022・fy2024・fy2025 は**ほぼ同一の型**で作られている。

> 言語に対する**新規の自作演算 `op`** を定義し、
> **(1)** 具体例を手計算させる
> **(2)** 具体的な正規言語に `op` を適用し、結果を**正規表現**（または CFG）で表させる
> **(3)** DFA（複数のこともある）から `op(L)` を受理する **NFA/DFA を構成**させる
> **(4)** 「**文脈自由言語は `op` で閉じているか**」の真偽を問い、真なら構成、偽なら反例を要求する

### 演算の履歴

| 年度 | 演算 | (4) の真偽 |
|---|---|---|
| fy2020 | 言語代入 `L{a↦L_a, b↦L_b}` | （(4) は DFA 構成） |
| fy2021 夏 | パターン出現位置への変換 `f_w` | **真**（有理変換） |
| fy2022 | HALF（前半）`Γ(L) = {v : ∃w, |v|=|w|, vw ∈ L}` | **偽** |
| fy2023 | 後ろから `k` 番目が `a`（＋反復補題・状態数下界 `2^k`） | — |
| fy2024 | 平方根 `H(L) = {w : ww ∈ L}` | **偽** |
| fy2025 | 部分列除去 `L₁ ⊖ L₂` | **真** |

真偽は 真→偽→偽→真 で、**交互ではないがほぼ半々**。「(3) が正則で閉じる」→「(4) で CF に持ち上げて真偽を問う」という構造は共通。

### まだ出ていない定番演算

- **シャッフル（interleaving）** `L₁ ⧢ L₂`：正則同士は正則、CF と正則も CF、しかし **CF 同士は CF でない** — テンプレートの (3)(4) にそのまま乗る
- **循環シフト** `CYCLE(L) = {vu : uv ∈ L}`：正則でも CF でも閉じる（真の側）
- **商** `L₁/L₂ = {u : ∃v∈L₂, uv∈L₁}`
- 挿入 `INSERT`、部分文字列（factor）集合、`{ww : w ∈ L}`（重複）、最短語

| 年度 | 内容 |
|---|---|
| fy2020 | Mealy 型 FSM・ワンホット符号化・CMOS トランジスタ数制限（12個以下） |
| fy2021 夏 | データ依存の列挙・被ロードハザード・サイクル数と IPC・動的分岐予測 |
| fy2021 冬 | 多数決回路（2入力NAND 6個以下）・D-FF 内部構造・同期順序回路 |

**毎年必ず出るもの**: サイクル数／CPI／IPC の計算（多くは「与えられたサイクル数から未知数を逆算」する形）。
**隔年で出るもの**: ゲート数・トランジスタ数を**厳しく制限した回路設計**（fy2020, fy2021冬, fy2025）。制限値は常に最適解ちょうどに設定される。
**頻出**: キャッシュ（fy2022, fy2023, fy2024）。

### 未出領域

IEEE 754 浮動小数点表現、キャッシュコヒーレンシ／マルチコア、アウトオブオーダ実行・スーパースカラ、多階層メモリの平均アクセス時間、仮想記憶とキャッシュのインデックス方式（VIPT/PIPT）。

## 2.2 各枠の題材履歴と未出領域

### 第1問（線形代数）

出題済み: 行列指数関数、二次形式と二次曲線、ヴァンデルモンド・補間、直交射影・最小二乗、鏡映変換（Householder）、正定値平方根・極分解。

共通する作り: **「行列の分解・変換」を定義し、幾何的な意味づけ（楕円・射影・鏡映・回転）を与えて、最後に一意性の証明か具体的な構成を要求する**。

未出領域: **特異値分解 (SVD)**、ジョルダン標準形、QR 分解／グラム・シュミット、擬似逆行列（fy2023 で最小二乗としては部分的に登場）、コレスキー分解、スペクトル半径とべき乗法、行列のランクと連立一次方程式の可解性。

### 第2問（解析）

出題済み: 曲線論（fy2019）、Frullani 積分＋一様収束（fy2021）、線形 ODE（fy2022）、ガンマ関数（fy2023）、周期係数 ODE（fy2024）、Riccati 方程式（fy2025）。

**ODE 系が fy2022・fy2024・fy2025 で3回、しかも2年連続中**。積分・特殊関数系は fy2021・fy2023 と隔年で挟まっている。

未出領域: ラプラス変換、フーリエ級数・フーリエ変換、多変数の極値とラグランジュ未定乗数、重積分の変数変換（ヤコビアン）、陰関数定理、級数の収束判定・べき級数。

### 第3問（確率）

出題済み: 秘書問題・最適停止（fy2019）、一様分布の積（fy2021）、母関数と待ち時間（fy2022）、幾何分布・母関数・相関（fy2023）、漸化式と複素特性根（fy2024）、集中不等式（fy2025）。

共通する作り: **離散確率が主流**で、**漸化式または母関数**を経由して閉形式を出させるものが半数以上（fy2022・fy2023・fy2024）。連続分布は fy2021 のみ。

未出領域: **マルコフ連鎖（定常分布・吸収確率・期待到達時間）**、ポアソン過程、順序統計量、最尤推定・ベイズ推定、中心極限定理、条件付き期待値を主題にしたもの。

## 3.1 形式

一括方式は大問間で時間を融通できるため、**難問1つに時間を寄せる戦術が使える**ぶん受験者に有利。逆に fy2021〜fy2023 の数学（1題50分の独立枠）は最も窮屈だった。

# 4. fy2026（2026年8月実施）の予想

確度は **高**（構造的にほぼ確実）／**中**（有力だが他候補あり）／**低**（穴を突いた予想）で示す。

## 4.1 数学

### 第1問 — 線形代数【確度: 高（枠自体）】

| 予想題材 | 確度 | 根拠 |
|---|---|---|
| **特異値分解 (SVD) と低ランク近似** | 中 | fy2025 の極分解 `F = SU` は SVD の片割れ。`S = UΣUᵀ` と展開すれば直結する自然な続き。「一意性の証明」というこの枠の定番も乗せやすい |
| **擬似逆行列と最小二乗（過決定系・劣決定系）** | 中 | fy2023 の最小二乗の一般化。射影行列 `A(AᵀA)⁻¹Aᵀ` の性質を問う形 |
| QR 分解・グラム・シュミットの直交化 | 低 | 未出だが計算主体になりやすく、この枠の「一意性の証明」の型に乗せにくい |
| ジョルダン標準形と `exp(At)` | 低 | fy2019 で行列指数関数が出ており、間隔としては再登場の頃合い |

**想定される小問構成**（この枠の定型）:
(1) 具体的な 3×3 行列で計算 → (2) 一般論の存在・一意性の証明 → (3) 幾何的な意味づけ（射影・回転・楕円）→ (4) 応用（最小化問題・面積・階数）

### 第2問 — 解析【確度: 高（枠自体）】

| 予想題材 | 確度 | 根拠 |
|---|---|---|
| **ラプラス変換（および ODE への応用）** | 中 | 未出。ODE 系が3回続いた流れを保ちつつ変換論に移れる中間地点。「変換の性質を示す → 具体的な ODE を解く」という誘導形式に最適 |
| **広義積分・特殊関数**（ベータ関数、ディリクレ積分など） | 中 | ODE が fy2024・fy2025 と2年連続なので、fy2021・fy2023 と同様に積分側へ戻る番 |
| フーリエ級数・変換 | 低 | 未出。情報系との親和性は高いが、この枠は素の微積分寄りの傾向 |
| 多変数の極値・ラグランジュ未定乗数・重積分の変数変換 | 低 | 未出領域だが、この枠は1変数解析に偏っている |

### 第3問 — 確率【確度: 高（枠自体）】

| 予想題材 | 確度 | 根拠 |
|---|---|---|
| **マルコフ連鎖（定常分布・吸収確率・期待到達時間）** | 中〜高 | 6年間で一度も出ていない最大の穴。かつ**第1問の線形代数（固有値・固有ベクトル）と接続する**ため、この研究科の好む「科目横断」に合致。漸化式主体という第3問の傾向とも整合 |
| **母関数を用いた待ち時間・分岐過程** | 中 | fy2022・fy2023 の直系。この枠で最も再現率の高い型 |
| 順序統計量・最大値/最小値の分布 | 低 | fy2021 の (4) で部分的に登場済み |
| ポアソン過程・指数分布 | 低 | 未出。連続分布はこの枠で手薄 |

**想定される小問構成**: (1)(2) 小さい `n` での具体計算 → (3) 一般の `n` の漸化式 → (4) 母関数または特性方程式で閉形式 → (5) 極限・近似・不等式

## 4.2 CS 専門科目

### 問題1 — 形式言語・オートマトン【確度: 高】

fy2022 以降4年連続で問題1がこの分野。**fy2026 も問題1で出ると見てよい**。

| 予想題材 | 確度 | 根拠 |
|---|---|---|
| **シャッフル（interleaving）`L₁ ⧢ L₂`** | 中〜高 | 未出の最有力。テンプレートに完璧に乗る: (1) 具体計算、(2) `(ab)* ⧢ {c}` などの正規表現、(3) 2つの DFA から NFA（状態は `Q₁×Q₂`、fy2025 の `⊖` とほぼ同じ構成）、(4) 「CF ⧢ 正則は CF、**CF ⧢ CF は CF でない**」— 真偽どちらも作れる |
| **循環シフト `CYCLE(L) = {vu : uv ∈ L}`** | 中 | 未出。正則でも CF でも閉じるので (4) は「真＋構成」型。fy2025 と同じ真の側 |
| 商 `L₁/L₂`、挿入、`{ww : w∈L}` | 低 | いずれも未出だが上2つより型に嵌めにくい |

**小問構成はほぼ確実に**: (1) 手計算 → (2) 正規表現 → (3) オートマトン構成 → (4) 文脈自由性の真偽と証明／反例。
**(4) の真偽は五分五分**だが、fy2025 が「真」だったので **fy2026 は「偽＋反例」の可能性がやや高い**（fy2022→fy2023 の並びも偽が続いた例がある）。

### 問題2 or 3 — OS【確度: 中〜高】

スケジューリング（fy2024）→ メモリ管理（fy2025）と交互に来ているので、**fy2026 はスケジューリング／同期の番**。

# 5. 対策への含意

1. **数学は分野が完全に固定されている**（線形代数／解析／確率）。この3分野だけを深く回すのが最も効率的で、範囲を広げる意味がほとんどない。
2. **CS も形式言語は毎年・問題1に固定**。しかも出題テンプレートが4年連続で同一なので、**「新規演算 → 正規表現 → オートマトン構成 → CF閉包性」の4点セットを型として練習する**のが最も費用対効果が高い。特に (3) の直積＋ε遷移構成と、(4) の閉包性論法（逆準同型 → 正則との交わり → 準同型像）は毎年使い回せる。
3. **アーキテクチャは「サイクル数の逆算」が毎年出る**。`総サイクル = 命令数 + (段数−1) + Σストール` の式を、どの未知数についても解けるようにしておく。
4. **各大問の最終小問には手を出さない判断も戦略**。配点の25〜30%がそこに集中するが正答率は一桁〜20%台で、それ以外を確実に拾えば合格者層の水準（数学76%／CS 68%）に届く設計が5年間再現されている。
5. **過去問演習は年度ごとの試験形式に合わせる**。fy2021〜fy2023 の数学は「1題50分・持ち越し不可」、fy2023 の CS は「2題70分×2」、fy2024 以降は「一括150分」。形式を揃えないと体感難度がずれる。
6. **冬入試の過去問を夏の指標にしない**。fy2021 冬は夏より 12 ポイント易しく、内容も教科書の定番のみだった。
