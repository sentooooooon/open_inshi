### 読み取れる構造

1. **形式言語・オートマトンは毎年必ず1題**。しかも **fy2022 以降は4年連続で問題1**に固定されている。
2. **計算機アーキテクチャ／論理回路も毎年必ず1題**。
3. **アルゴリズム・離散数学も毎年必ず1題**。
4. **OS は隔年寄り**。fy2022・fy2024・fy2025 に出題、fy2020・fy2023 は非出題。OS が無い年はその枠に**プログラム意味論**（fy2023）や**機械学習**（fy2020）が入る。
5. 4分野の「並び順」は固定されていないが、fy2024・fy2025 は
   `形式言語 → (OS または アーキ) → (アーキ または OS) → アルゴリズム`
   という同型配置。

## 1.2 形式言語問題の出題テンプレート

fy2020・fy2022・fy2024・fy2025 は**ほぼ同一の型**で作られている。

> 言語に対する**新規の自作演算 `op`** を定義し、
> **(1)** 具体例を手計算させる
> **(2)** 具体的な正規言語に `op` を適用し、結果を**正規表現**（または CFG）で表させる
> **(3)** DFA（複数のこともある）から `op(L)` を受理する **NFA/DFA を構成**させる
> **(4)** 「**文脈自由言語は `op` で閉じているか**」の真偽を問い、真なら構成、偽なら反例を要求する

### 演算の履歴

| 年度 | 演算 | (4) の真偽 |
|---|---|---|
| fy2020 | 言語代入 `L{a↦L_a, b↦L_b}` | （(4) は DFA 構成） |
| fy2021 夏 | パターン出現位置への変換 `f_w` | **真**（有理変換） |
| fy2022 | HALF（前半）`Γ(L) = {v : ∃w, |v|=|w|, vw ∈ L}` | **偽** |
| fy2023 | 後ろから `k` 番目が `a`（＋反復補題・状態数下界 `2^k`） | — |
| fy2024 | 平方根 `H(L) = {w : ww ∈ L}` | **偽** |
| fy2025 | 部分列除去 `L₁ ⊖ L₂` | **真** |

真偽は 真→偽→偽→真 で、**交互ではないがほぼ半々**。「(3) が正則で閉じる」→「(4) で CF に持ち上げて真偽を問う」という構造は共通。

### 演算の履歴（訂正版）

**`fy2019` 問題1 が シャッフル `L₁ ⊗ L₂` そのものだった。** 当初「未出の最有力候補」としたのは誤りである（1.6 参照）。

まだ確認できていない演算: **循環シフト** `CYCLE(L) = {vu : uv ∈ L}`、**商** `L₁/L₂`、挿入 `INSERT`、部分文字列（factor）集合、`{ww : w ∈ L}`。ただし fy2014〜fy2018 は未調査なので、これらも既出の可能性がある。

## 2.2 各枠の題材履歴と未出領域

### 第1問（線形代数）

出題済み: **特異値分解 SVD（fy2011）**、ユニタリ行列・DFT行列（fy2018）、行列指数関数（fy2019）、二次形式と二次曲線（fy2021）、ヴァンデルモンド・補間（fy2022）、直交射影・最小二乗（fy2023）、鏡映変換 Householder（fy2024）、正定値平方根・極分解（fy2025）。

共通する作り: **「行列の分解・変換」を定義し、幾何的な意味づけ（楕円・射影・鏡映・回転）を与えて、最後に一意性の証明か具体的な構成を要求する**。

fy2017 以降に限れば未出の領域: ジョルダン標準形、QR 分解／グラム・シュミット、コレスキー分解、スペクトル半径とべき乗法、行列のランクと連立一次方程式の可解性、グラフのラプラシアン行列とスペクトル、巡回行列。

### 第2問（解析）

**ODE 系が fy2022・fy2024・fy2025 で3回、しかも2年連続中**。積分・特殊関数系は fy2021・fy2023 と隔年で挟まっている。

## 2.3 約14年周期の題材再利用 — fy2011 と fy2025

**fy2011 第1問は特異値分解 (SVD) そのものだった。**

| fy2011 第1問 | 内容 |
|---|---|
| (1) | `AᵀA` の固有値・固有ベクトル |
| (2) | `AᵀA = U Λ Uᵀ` の直交対角化 |
| (3) | **`B² = AᵀA` を満たす固有値がすべて正の `B` を一つ求めよ** |
| (4) | `C = (u₁/√λ₁, u₂/√λ₂, u₃/√λ₃)` に対し `AC` が直交行列であることを証明 |
| (5) | **`A = V diag(√λ₁,√λ₂,√λ₃) W`（`V, W` は直交行列）を求めよ** |

これを fy2025 第1問（`B²=A` の正定値対称解 → 平方根の一意性 → 極分解 `F = SU = VT`）と並べると、
**(3) は fy2025 (1)(ii)・(2) と同一の題材**であり、**(4)(5) は極分解と数学的にほぼ同値**（`F = SU` の `S` をスペクトル分解すれば SVD になる）。

つまり **fy2025 は fy2011 を14年ぶりに再利用した回**である。この事実から2つの結論が出る。

1. **「fy2017 以降に出ていない」＝「出題範囲外」ではない**。10年以上の間隔で同じ素材が戻る。本ファイルの「未出領域」はすべてこの留保付きで読むこと。
2. **同じ素材を短期間で繰り返すことはない**。fy2025 がこの領域を消化した直後なので、fy2026 に SVD が来る確率はむしろ**下がる**。

## 2.4 確率枠（第3問）の全年度調査 — 「未出の穴」はほぼ存在しなかった

### 予測モデルの作り直し — 「道具」と「題材」を分けて考える

全年度を並べると、繰り返しの周期が2種類あることが分かる。

**(a) 道具は毎年のように再登場する（周期1〜3年）**

- 確率母関数: fy2006 → fy2011 → fy2022 → fy2023
- 確率漸化式: fy2008 → fy2012 → fy2013 → fy2024
- 固有値・対角化: ほぼ毎年
- ランダムウォーク: fy2008 → fy2010（2年間隔）
- 指数分布・連続分布の変数変換: fy2009 → fy2016 → fy2018 → fy2021

**(b) 特徴的な「題材（ガワ）」は10年以上空けて回る（周期10〜17年）**

- 正定値平方根・SVD 系: fy2011 → fy2025（14年）
- 秘書問題・最適停止: fy2019 のみ
- Steiner の公式・曲線論: fy2019 のみ
- クーポンコレクター: fy2011 のみ

**したがって、「どの題材が出るか」を当てにいくのは筋が悪い。** 題材は10年以上のスパンで回るので単年の予測は当たらず、一方で**道具は毎年出る**。対策の投資先は (a) の道具に集中させるべきであり、本ファイルの「予想」セクションは**題材当てではなく、道具の優先順位を裏づけるための材料**として読むのが正しい。

# 5. 対策への含意

1. **数学は分野が完全に固定されている**（線形代数／解析／確率）。この3分野だけを深く回すのが最も効率的で、範囲を広げる意味がほとんどない。
2. **CS も形式言語は毎年・問題1に固定**。しかも出題テンプレートが4年連続で同一なので、**「新規演算 → 正規表現 → オートマトン構成 → CF閉包性」の4点セットを型として練習する**のが最も費用対効果が高い。特に (3) の直積＋ε遷移構成と、(4) の閉包性論法（逆準同型 → 正則との交わり → 準同型像）は毎年使い回せる。
3. **アーキテクチャは「サイクル数の逆算」が毎年出る**。`総サイクル = 命令数 + (段数−1) + Σストール` の式を、どの未知数についても解けるようにしておく。
4. **各大問の最終小問には手を出さない判断も戦略**。配点の25〜30%がそこに集中するが正答率は一桁〜20%台で、それ以外を確実に拾えば合格者層の水準（数学76%／CS 68%）に届く設計が5年間再現されている。
5. **過去問演習は年度ごとの試験形式に合わせる**。fy2021〜fy2023 の数学は「1題50分・持ち越し不可」、fy2023 の CS は「2題70分×2」、fy2024 以降は「一括150分」。形式を揃えないと体感難度がずれる。
6. **冬入試の過去問を夏の指標にしない**。fy2021 冬は夏より 12 ポイント易しく、内容も教科書の定番のみだった。
