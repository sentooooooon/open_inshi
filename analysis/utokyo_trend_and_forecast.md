# 0. 先に結論

**1. この研究科に「未出の穴」はほぼ存在しない。**
6〜8年の窓で「未出だから狙い目」に見えた題材は、窓を24回分・25年分に広げるとほぼ全部既出だった。動的計画法・シャッフル・マルコフ連鎖・SVD・順序統計量・Union-Find・乱択アルゴリズム・情報理論・決定可能性、いずれも既出である。本当に一度も出ていないのは 循環シフト／ファイルシステム／最大流／IEEE 754／NP完全性 程度で、いずれも配点比重が小さい。

**2. 信頼できるのは「枠」であって「題材」ではない。**
25年通しで外れたことがないのは次の3点だけ。ここに対策を寄せるのが、どの題材予想よりも期待値が高い。

| 事実 | 継続年数 |
|---|---|
| 数学は 線形代数／解析／確率 の3枠固定・各1題 | fy2007 以降19年 |
| CS 問題1 は形式言語で、「新演算 → 正規表現 → オートマトン構成 → CF閉包性」の4点セット | 夏は fy2022 以降4年、冬を含めると fy2018 以降ほぼ毎回 |
| CS にアーキテクチャ／論理回路が1題 | fy2020 以降6年 |

**3. 冬入試は夏の予告編である。**
fy2025 問題3(1)（XOR を NAND 5個以下）は **fy2020冬 問題2(1) とほぼ同一問題**。fy2025 問題1（部分列除去）は **fy2018冬 問題3（部分列）の7年後の再利用**。形式言語のテンプレート自体が冬入試（fy2018冬・fy2019冬・fy2020冬）で先に確立して夏へ移っている。**冬入試8回分は、夏の対策として最も費用対効果の高い演習素材**である。

## 1.3 形式言語 — テンプレートと演算の全履歴

### テンプレート

> 言語に対する**新規の自作演算 `op`** を定義し、
> **(1)** 具体例を手計算させる
> **(2)** 具体的な正規言語に `op` を適用し、結果を**正規表現**（または CFG）で表させる
> **(3)** DFA（複数のこともある）から `op(L)` を受理する **NFA/DFA を構成**させる
> **(4)** 「**文脈自由言語は `op` で閉じているか**」の真偽を問い、真なら構成、偽なら反例を要求する

このテンプレートは**夏ではなく冬入試で先に確立**し、fy2022 以降に夏の問題1 へ移った。

### 演算の全履歴（24回分）

| 年度 | 演算 | 夏/冬 | (4) の形 |
|---|---|---|---|
| fy2014 夏 II-2 | 言語方程式 `L = S·L + T`（アーデンの補題） | 夏 | 最小解・一意性の証明 |
| fy2018 冬 問題3 | 部分列 `v ⪯ w`（上方閉包・下方閉包） | 冬 | 構成の正当性証明 |

| fy2019 冬 問題4 | **逆準同型 `f⁻¹(L)`** | 冬 | 構成の正当性証明 |
| fy2020 夏 問題2 | 言語代入 `L{a↦L_a}` | 夏 | DFA 構成 |
| fy2020 冬 問題3 | **商 `L₁ ◁ L₂`** | 冬 | CF 閉包性の真偽 |
| fy2021 夏 問題3 | パターン出現位置への変換 `f_w` | 夏 | 真（有理変換） |
| fy2021 冬 問題3 | `w^R b a w` | 冬 | — |
| fy2022 問題1 | HALF `Γ(L) = {v : ∃w, |v|=|w|, vw ∈ L}` | 夏 | **偽** |

| fy2025 問題1 | 部分列除去 `L₁ ⊖ L₂` | 夏 | **真** |

**再利用の間隔は5〜8年**（部分列 fy2018冬 → 部分列除去 fy2025夏 で7年）。数学の10〜17年よりずっと短い。

**24回分を通してまだ出ていない主要演算は「循環シフト `CYCLE(L) = {vu : uv ∈ L}`」だけ**である。商・逆準同型・シャッフル・言語代入・部分列・HALF・平方根はすべて消化済み。

# 5. 対策への含意

1. **「未出だから狙う」をやめる。** 6〜8年の窓で未出に見えた題材は、24回分・25年分に広げるとほぼ全部既出だった。残る本当の未出は 循環シフト／ファイルシステム／最大流／IEEE 754／NP完全性 程度で、いずれも配点比重が小さい。

2. **数学は分野が完全に固定されている**（線形代数／解析／確率）。この3分野を深く回すのが最も効率的で、範囲を広げる意味がほとんどない。

3. **CS の形式言語は毎年・問題1に固定。** 出題テンプレートは冬入試を含めて fy2018 以降ほぼ毎回同一なので、**「新規演算 → 正規表現 → オートマトン構成 → CF閉包性」の4点セットを型として練習する**のが最も費用対効果が高い。特に (3) の直積 `Q₁×Q₂` ＋ε遷移構成と、(4) の閉包性論法（逆準同型 → 正則との交わり → 準同型像）は毎年使い回せる。

4. **冬入試の過去問は「難易度の指標」ではなく「題材の予告編」として使う。** fy2018冬・fy2019冬・fy2020冬 の形式言語3題と、fy2015冬・fy2020冬・fy2021冬 の回路3題は夏と完全に同型。**冬入試8回分は夏の対策として最も費用対効果の高い演習素材**である（易しいのは事実なので、得点率の自己評価には使わない）。

5. **数学の過去問は CS の対策にもなる（逆も）。** 2.6 の対応表を参照。

6. **アーキテクチャは「サイクル数の逆算」が毎年出る。** `総サイクル = 命令数 + (段数−1) + Σストール` を、どの未知数についても解けるようにしておく。キャッシュは6回で最頻。

7. **各大問の最終小問には手を出さない判断も戦略。** 配点の25〜30%がそこに集中するが正答率は一桁〜20%台で、それ以外を確実に拾えば合格者層の水準（数学76%／CS 68%）に届く設計が5年間再現されている。

8. **過去問演習は年度ごとの試験形式に合わせる。** fy2021〜fy2023 の数学は「1題50分・持ち越し不可」、fy2023 の CS は「2題70分×2」、fy2024 以降は「一括150分」、fy2019 以前の CS は「専門 I ＋ 専門 II の2冊子制」。

分野別の優先順位と学習順序は [`utokyo_study_priority.md`](./utokyo_study_priority.md) を参照。
