### 読み取れる構造

1. **形式言語・オートマトンは毎年必ず1題**。しかも **fy2022 以降は4年連続で問題1**に固定されている。
2. **計算機アーキテクチャ／論理回路も毎年必ず1題**。
3. **アルゴリズム・離散数学も毎年必ず1題**。
4. **OS は隔年寄り**。fy2022・fy2024・fy2025 に出題、fy2020・fy2023 は非出題。OS が無い年はその枠に**プログラム意味論**（fy2023）や**機械学習**（fy2020）が入る。
5. 4分野の「並び順」は固定されていないが、fy2024・fy2025 は
   `形式言語 → (OS または アーキ) → (アーキ または OS) → アルゴリズム`
   という同型配置。

## 1.2 形式言語問題の出題テンプレート

fy2020・fy2022・fy2024・fy2025 は**ほぼ同一の型**で作られている。

> 言語に対する**新規の自作演算 `op`** を定義し、
> **(1)** 具体例を手計算させる
> **(2)** 具体的な正規言語に `op` を適用し、結果を**正規表現**（または CFG）で表させる
> **(3)** DFA（複数のこともある）から `op(L)` を受理する **NFA/DFA を構成**させる
> **(4)** 「**文脈自由言語は `op` で閉じているか**」の真偽を問い、真なら構成、偽なら反例を要求する

### 演算の履歴

| 年度 | 演算 | (4) の真偽 |
|---|---|---|
| fy2020 | 言語代入 `L{a↦L_a, b↦L_b}` | （(4) は DFA 構成） |
| fy2021 夏 | パターン出現位置への変換 `f_w` | **真**（有理変換） |
| fy2022 | HALF（前半）`Γ(L) = {v : ∃w, |v|=|w|, vw ∈ L}` | **偽** |
| fy2023 | 後ろから `k` 番目が `a`（＋反復補題・状態数下界 `2^k`） | — |
| fy2024 | 平方根 `H(L) = {w : ww ∈ L}` | **偽** |
| fy2025 | 部分列除去 `L₁ ⊖ L₂` | **真** |

真偽は 真→偽→偽→真 で、**交互ではないがほぼ半々**。「(3) が正則で閉じる」→「(4) で CF に持ち上げて真偽を問う」という構造は共通。

### 演算の履歴（訂正版）

**`fy2019` 問題1 が シャッフル `L₁ ⊗ L₂` そのものだった。** 当初「未出の最有力候補」としたのは誤りである（1.6 参照）。

まだ確認できていない演算: **循環シフト** `CYCLE(L) = {vu : uv ∈ L}`、**商** `L₁/L₂`、挿入 `INSERT`、部分文字列（factor）集合、`{ww : w ∈ L}`。ただし fy2014〜fy2018 は未調査なので、これらも既出の可能性がある。

> **→ 1.7 で決着した。** fy2014〜fy2025 の夏・冬あわせて24回分をすべて読んだ結果、**商 `L₁◁L₂` は fy2020冬、逆準同型は fy2019冬、部分列は fy2018冬で既出**。**24回分を通して未出の主要演算は「循環シフト」だけ**である。この節の演算履歴表は 1.7.3 の完全版で置き換えて読むこと。

### 構造の変化

1. **fy2019 以前**: 専門科目 I + II の6題制。論理・NLP／ML・CG・文字列アルゴリズムまで含む広い範囲。

## 2.3 約14年周期の題材再利用 — fy2011 と fy2025

**fy2011 第1問は特異値分解 (SVD) そのものだった。**

| fy2011 第1問 | 内容 |
|---|---|
| (1) | `AᵀA` の固有値・固有ベクトル |

| (3) | **`B² = AᵀA` を満たす固有値がすべて正の `B` を一つ求めよ** |
| (4) | `C = (u₁/√λ₁, u₂/√λ₂, u₃/√λ₃)` に対し `AC` が直交行列であることを証明 |
| (5) | **`A = V diag(√λ₁,√λ₂,√λ₃) W`（`V, W` は直交行列）を求めよ** |

これを fy2025 第1問（`B²=A` の正定値対称解 → 平方根の一意性 → 極分解 `F = SU = VT`）と並べると、
**(3) は fy2025 (1)(ii)・(2) と同一の題材**であり、**(4)(5) は極分解と数学的にほぼ同値**（`F = SU` の `S` をスペクトル分解すれば SVD になる）。

1. **「fy2017 以降に出ていない」＝「出題範囲外」ではない**。10年以上の間隔で同じ素材が戻る。本ファイルの「未出領域」はすべてこの留保付きで読むこと。
2. **同じ素材を短期間で繰り返すことはない**。fy2025 がこの領域を消化した直後なので、fy2026 に SVD が来る確率はむしろ**下がる**。

> **【2.5 による訂正】** この節の「約14年周期」は**周期を過大に見積もっている**。fy2001〜fy2005 まで遡ると **fy2005 第5問（半正定値行列・`X = AᵀA`・`tr XY ≥ 0`）が同じ系譜の3つ目**として見つかり、系列は **fy2005 → fy2011（6年）→ fy2025（14年）** となる。さらに **CS fy2020冬 問題4 が SVD＋擬似逆行列**なので、研究科全体としては5年間隔で触れている題材である。

- 確率漸化式: fy2008 → fy2012 → fy2013 → fy2024

**したがって、「どの題材が出るか」を当てにいくのは筋が悪い。** 題材は10年以上のスパンで回るので単年の予測は当たらず、一方で**道具は毎年出る**。対策の投資先は (a) の道具に集中させるべきであり、本ファイルの「予想」セクションは**題材当てではなく、道具の優先順位を裏づけるための材料**として読むのが正しい。

### 2.5.2 25年通しての結論

fy2001〜fy2025 の25年・のべ100題以上を通して見ると、

- **「未出の穴」という概念は、この研究科に対しては機能しない。** 6年・8年の窓で「未出」に見えたものは、窓を25年に広げるとほぼ全部既出になる。
- **残っているのは「頻度」だけ**である。固有値・対角化（ほぼ毎年）、母関数（5回）、確率漸化式（5回）、複素解析（4回）、順序統計量（4回）、ランダムウォーク（4回）、正定値・スペクトル分解（3回）。
- したがって**予想は「頻度の高い道具から順に潰す」以上のことはできない**。以下の第4章はそのつもりで読むこと。

# 5. 対策への含意（全年度調査後・改訂版）

1. **「未出だから狙う」をやめる。** 6〜8年の窓で未出に見えた題材は、25年に広げるとほぼ全部既出だった（シャッフル・動的計画法・マルコフ連鎖・SVD・順序統計量・Union-Find・乱択・情報理論、すべて）。**残っている本当の未出は「循環シフト」「ファイルシステム」「最大流」「IEEE 754」「NP完全性」程度**で、いずれも配点上の比重は小さい。
2. **数学は分野が完全に固定されている**（線形代数／解析／確率）。この3分野だけを深く回すのが最も効率的で、範囲を広げる意味がほとんどない。
3. **CS も形式言語は毎年・問題1に固定**。出題テンプレートは**夏だけでなく冬入試も含めて fy2018 以降ほぼ毎回同一**なので、**「新規演算 → 正規表現 → オートマトン構成 → CF閉包性」の4点セットを型として練習する**のが最も費用対効果が高い。特に (3) の直積＋ε遷移構成と、(4) の閉包性論法（逆準同型 → 正則との交わり → 準同型像）は毎年使い回せる。
4. **冬入試の過去問は「難易度の指標」ではなく「題材の予告編」として使う。** fy2020冬 問題2(1)（XOR を NAND 5個）は **fy2025 問題3(1) とほぼ同一問題**、fy2018冬 問題3（部分列）は **fy2025 問題1（部分列除去）の6年前の原型**、fy2019冬 問題4（逆準同型）・fy2020冬 問題3（商）は夏の問題1 の型そのもの。**冬入試 fy2014〜fy2021 の8回分は、夏の対策として最も費用対効果の高い演習素材**である（難易度が低いのは事実なので、得点率の自己評価には使わないこと）。
5. **数学の過去問は CS の対策にもなる（逆も）。** 数学 fy2002 第3問（リストスケジューリング 2近似）＝ CS fy2022 問題2、数学 fy2005 第1問（有限集合上の不動点）＝ CS fy2015 I-2（DFA 最小化）、数学 fy2011/2025（SVD・正定値）＝ CS fy2020冬 問題4。**両科目の委員会は題材を共有している。**
6. **アーキテクチャは「サイクル数の逆算」が毎年出る**。`総サイクル = 命令数 + (段数−1) + Σストール` の式を、どの未知数についても解けるようにしておく。キャッシュは6回既出で最頻。
7. **各大問の最終小問には手を出さない判断も戦略**。配点の25〜30%がそこに集中するが正答率は一桁〜20%台で、それ以外を確実に拾えば合格者層の水準（数学76%／CS 68%）に届く設計が5年間再現されている。
8. **過去問演習は年度ごとの試験形式に合わせる**。fy2021〜fy2023 の数学は「1題50分・持ち越し不可」、fy2023 の CS は「2題70分×2」、fy2024 以降は「一括150分」。fy2019 以前の CS は「専門 I（3題90分）＋専門 II（4〜6題150分、選択制の年あり）」で、そのままでは現行形式の演習にならない。
