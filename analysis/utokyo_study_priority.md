# 東大情報理工 分野別 対策優先順位

`utokyo_trend_and_forecast.md` の傾向分析（数学 fy2017–fy2025 の8年、CS fy2020–fy2025 の6年＋冬1回）から導いた、**やる順番つきの対策範囲**。

## 優先度の定義

| 記号 | 意味 | 目安 |
|---|---|---|
| **S** | 毎年必ず使う。ここが穴だと即失点 | 最初に完成させる。合計の6割の時間を投下 |
| **A** | 高頻度（8年で3回以上）または S の前提 | S の次に着手 |
| **B** | 周期的に回る／未出だが射程内の穴 | 直前期に一巡 |
| **C** | 単発・費用対効果が低い | 余裕があれば。捨ててもよい |

配点シェアは「その論点が絡む小問の配点合計 ÷ 全配点」の推定値。

## このファイルの位置づけ

- 頻度は過去問の実測、優先度は**そこからの推論**。大学からの情報に基づくものではない。
- **「未出」の判定は調査済み年度（数学 fy2011・fy2017〜fy2025、CS fy2020〜fy2025）に限る。** fy2011 の調査で約14年周期の題材再利用が確認されたため、未調査年度に同じ題材がある可能性は高い。
- リポジトリ README の収録方針に抵触するため、**作業ブランチ限りの成果物**。master へのマージは想定しない。

# 2. CS 専門科目

4分野（形式言語／アーキテクチャ／アルゴリズム／OS）のうち**前3つは毎年必ず1題**、OS は6年中4年。

## 2.1 形式言語・オートマトン（毎年・問題1固定・配点の 1/4）

**この科目で最も投資効率が高い分野**。4年連続で同一テンプレートなので、型を押さえると丸ごと取れる。

# 3. 学習順序の推奨

## フェーズ1（土台・全体の50%の時間）

**S 級だけを回す。**

- 数学: 固有値/対角化 → 実対称・二次形式 → 1階ODE全解法 → 期待値/分散/漸化式/母関数
- CS: 正則言語の構成法（`Q₁×Q₂`＋ε遷移）→ CFL閉包性の3段論法 → パイプラインのサイクル数計算 → キャッシュ構成 → 証明の書き方（不変量）

この段階で**数学65%／CS 55%**に届く。

## フェーズ2（頻出の肉付け・30%）

A 級を追加。特に:
- 数学: 広義積分・一様収束・連続分布の変数変換
- CS: ゲート数制約回路（実際に手で描く）、スケジューリングのシミュレーション、グラフアルゴリズム

この段階で**数学75%／CS 65%**、合格者層の水準。

## フェーズ3（穴埋め・直前期・20%）

B 級のうち fy2026 予想と重なるものだけ:
- 数学: **SVD／擬似逆行列**、**マルコフ連鎖**、ラプラス変換の概要
- CS: **シャッフル `L₁⧢L₂` と循環シフト `CYCLE(L)`** を自分で解く、**動的計画法**、最大流最小カット

## やらなくてよいもの

- 数学: 微分幾何・曲線論、多変数の極値、統計的推定、測度論
- CS: チューリング機械・決定可能性、NP完全性の詳細、文字列アルゴリズム、機械学習（fy2020 の単発）、分散システム、データベース、ネットワーク
