# 東大情報理工 分野別 対策優先順位

`utokyo_trend_and_forecast.md` の傾向分析（数学 fy2017–fy2025 の8年、CS fy2020–fy2025 の6年＋冬1回）から導いた、**やる順番つきの対策範囲**。

## 優先度の定義

| 記号 | 意味 | 目安 |
|---|---|---|
| **S** | 毎年必ず使う。ここが穴だと即失点 | 最初に完成させる。合計の6割の時間を投下 |
| **A** | 高頻度（8年で3回以上）または S の前提 | S の次に着手 |
| **B** | 周期的に回る／未出だが射程内の穴 | 直前期に一巡 |
| **C** | 単発・費用対効果が低い | 余裕があれば。捨ててもよい |

配点シェアは「その論点が絡む小問の配点合計 ÷ 全配点」の推定値。

## このファイルの位置づけ

- 頻度は過去問の実測、優先度は**そこからの推論**。大学からの情報に基づくものではない。
- **数学は fy2001・fy2006〜fy2016・fy2017〜fy2025 まで調査済み**（fy2002〜fy2005 のみ未調査）。CS は fy2020〜fy2025 のみ調査済みなので、CS の「未出」判定は依然として弱い。
- 全年度調査の結果、**「未出だから次に出る」という推論はほぼ成立しない**ことが分かった。題材（ガワ）は10〜17年周期で回り、道具（母関数・漸化式・固有値・ODE解法）は毎年出る。**投資先は道具**。
- リポジトリ README の収録方針に抵触するため、**作業ブランチ限りの成果物**。master へのマージは想定しない。

**予想対策の訂正（2回目・全年度調査後）**:
- **シャッフル `L₁⧢L₂` は fy2019夏 I-1 で既出**（予想としては完全に無効。ただし演習素材としては最良）。
- **商 `L₁◁L₂` は fy2020冬 問題3、逆準同型 `f⁻¹(L)` は fy2019冬 問題4 で既出**。ただし**夏では未出**で、冬→夏の移植は fy2018冬（部分列）→fy2025夏（部分列除去）の前例がある。
- **24回分（夏12・冬8ほか）を通して唯一まだ出ていない主要演算は「循環シフト `CYCLE(L)`」**。ただし CF 閉包性が研究レベルなので (4) は正則止まりになるはず。

# 3. 学習順序の推奨

> **【全年度調査を反映して改訂】** 旧版のフェーズ3は「未出の穴を埋める」設計だったが、その「穴」がほぼ全部既出だったため、**フェーズ3を「演習量を積む」設計に変更**した。

## フェーズ1（土台・全体の50%の時間）

**S 級だけを回す。**

- 数学: 固有値/対角化 → 実対称・二次形式 → 1階ODE全解法 → 期待値/分散/漸化式/母関数
- CS: 正則言語の構成法（`Q₁×Q₂`＋ε遷移）→ CFL閉包性の3段論法 → パイプラインのサイクル数計算 → キャッシュ構成 → **ゲート数制約回路** → **相互排除・デッドロック** → 証明の書き方（不変量）

この段階で**数学65%／CS 55%**に届く。

## フェーズ2（頻出の肉付け・30%）

A 級を追加。特に:
- 数学: 広義積分・一様収束・連続分布の変数変換・**複素解析（留数と主値積分）**・**マルコフ連鎖**・**集中不等式**
- CS: 順序回路とタイミングチャート、スケジューリングのシミュレーション、最小全域木、**計算量の下界・帰着**、**乱択アルゴリズム**、**決定可能性と CFG×DFA の直積**

この段階で**数学75%／CS 65%**、合格者層の水準。

## フェーズ3（演習量・直前期・20%）— 設計変更

**「未出の穴を埋める」のはやめる**（穴がほぼ存在しないことが判明したため）。代わりに、**同一題材の別年度版を解いて型を固める**。

| 優先 | 演習セット | 理由 |
|---|---|---|
| 1 | **CS 冬入試 fy2018冬・fy2019冬・fy2020冬 の形式言語（部分列・逆準同型・商）** | 夏の問題1 と完全に同型。3題で型が固まる |
| 2 | **CS 回路 fy2015冬 問題4／fy2020冬 問題2／fy2021冬 問題4／fy2020夏 問題3／fy2025 問題3** | ゲート制約回路5題。**fy2025 は fy2020冬 の再利用**なので、逆に fy2020冬 を解けば fy2025 が解ける |
| 3 | **数学 fy2005 第5問／fy2011 第1問**（PSD・SVD） | fy2025 第1問と同一題材の原型 |
| 4 | **数学 fy2003 第5問／fy2004 第5問／fy2005 第3問**（複素解析3題） | 解析枠で「順番が来ている」候補。17年空いている |
| 5 | **数学 fy2004 第1問**（マルコフ連鎖＋固有値分解） | 第1問と第3問をまたぐ形の唯一の前例 |
| 6 | **CS fy2014 I-3（ナップサック DP）／fy2018 II-6（3SUM 帰着）／fy2015 I-1（フライヴァルズ）** | 4題制で12年登場していない領域の代表 |

## やらなくてよいもの

- 数学: 微分幾何・曲線論、測度論、マルチンゲール
- CS: NP完全性の詳細（SAT からの帰着）、ファイルシステム、ネットワーク、データベース、IEEE 754、キャッシュコヒーレンシ
- **共通: 「未出の題材を探して当てにいく」作業そのもの**（25年調査の結論として、投資対象にならない）
