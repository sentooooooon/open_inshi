# 問題 A — シャッフル（interleaving）

`Σ = {a, b, c, d}` とする。語 `u, v ∈ Σ*` に対して、**シャッフル** `u ⧢ v ⊆ Σ*` を以下のように帰納的に定義する。

```
ε ⧢ v = {v},   u ⧢ ε = {u},
(xu) ⧢ (yv) = x·(u ⧢ (yv))  ∪  y·((xu) ⧢ v)      (x, y ∈ Σ)
```

すなわち `u ⧢ v` は、`u` と `v` のそれぞれの文字の順序を保ったまま交互に混ぜて得られる語の集合を表す。
例えば `ab ⧢ c = {cab, acb, abc}` である。

さらに、言語 `L₁, L₂ ⊆ Σ*` に対して

```
L₁ ⧢ L₂ = ⋃_{u∈L₁, v∈L₂} (u ⧢ v)
```

と定義する。以下の問いに答えよ。

**(1)** `ab ⧢ ba` を求めよ。

**(2)** `L₁` を正規表現 `a*` で表される言語、`L₂` を正規表現 `(ab)*` で表される言語とする。`L₁ ⧢ L₂` を正規表現で表せ。

**(3)** `L₁, L₂` がそれぞれ決定性有限オートマトン `A₁, A₂` によって受理される `Σ` 上の言語であるとする。`L₁ ⧢ L₂` を受理する非決定性有限オートマトンを `A₁, A₂` から構成する方法を、簡単な説明とともに示せ。

**(4)** 以下の2つの命題について、それぞれ真であるか否かを答えよ。真であればその証明の概略を、そうでなければ簡単な説明とともに反例を示せ。

> **命題 1**: `Σ` 上のすべての言語 `L₁, L₂ ⊆ Σ*` について、`L₁` が正規言語かつ `L₂` が文脈自由言語ならば、`L₁ ⧢ L₂` は文脈自由言語である。
>
> **命題 2**: `Σ` 上のすべての言語 `L₁, L₂ ⊆ Σ*` について、`L₁` と `L₂` がともに文脈自由言語ならば、`L₁ ⧢ L₂` は文脈自由言語である。

# 問題 B — 循環シフト（cyclic shift）

`Σ = {a, b}` とする。言語 `L ⊆ Σ*` に対して、**循環シフト** `CYCLE(L) ⊆ Σ*` を以下によって定義する。

```
CYCLE(L) = { vu  |  u, v ∈ Σ*,  uv ∈ L }
```

すなわち `CYCLE(L)` は、`L` の語を任意の位置で2つに切り、前半と後半を入れ替えて得られる語全体からなる。
例えば `CYCLE({abc}) = {abc, bca, cab}` である（`Σ` に `c` が含まれる場合）。

以下の問いに答えよ。

**(1)** `CYCLE({abb, ba})` を求めよ。

**(2)** `L` を正規表現 `a*b*` で表される言語とする。`CYCLE(L)` を正規表現で表せ。

**(3)** `L` が決定性有限オートマトン `A = (Q, Σ, δ, q₀, F)` によって受理される言語であるとする。`CYCLE(L)` を受理する非決定性有限オートマトンを `A` から構成する方法を、簡単な説明とともに示せ。ε 遷移を用いてもよい。

**(4)** 任意の言語 `L ⊆ Σ*` について `CYCLE(CYCLE(L)) = CYCLE(L)` が成り立つことを示せ。

**(5)** 以下の命題が真であるか否かを答えよ。真であればその証明の概略（`CYCLE(L)` を生成する文脈自由文法の構成法を簡単な説明とともに示せばよい）を、そうでなければ簡単な説明とともに反例を示せ。

> **命題**: `Σ` 上のすべての言語 `L ⊆ Σ*` について、`L` が文脈自由言語ならば `CYCLE(L)` も文脈自由言語である。

## 問題 A (1)

定義に従って展開する。

```
b ⧢ a   = b·(ε ⧢ a) ∪ a·(b ⧢ ε) = {ba, ab}
b ⧢ ba  = b·(ε ⧢ ba) ∪ b·(b ⧢ a) = {bba} ∪ b·{ba, ab} = {bba, bab}
ab ⧢ a  = a·(b ⧢ a) ∪ a·(ab ⧢ ε) = a·{ba, ab} ∪ {aab} = {aba, aab}
ab ⧢ ba = a·(b ⧢ ba) ∪ b·(ab ⧢ a)
        = a·{bba, bab} ∪ b·{aba, aab}
```

**`ab ⧢ ba = {abba, abab, baba, baab}`**（4語）

## 問題 A (2)

**答: `L₁ ⧢ L₂ = (aa*b)*a*`**

**(⊆)** `w ∈ aᵐ ⧢ (ab)ⁿ` とする。`aᵐ` は `b` を含まないので `w` 中のすべての `b` は `(ab)ⁿ` 側から来る。したがって `#b(w) = n`。

混ぜ方を1つ固定すると、`w` の中の `n` 個の `a` が `(ab)ⁿ` 側の `a` として指定される。`(ab)ⁿ = a₁b₁a₂b₂⋯aₙbₙ` の順序が保たれるので、左から読んで

```
（指定 a₁）< b₁ < （指定 a₂）< b₂ < ⋯ < （指定 aₙ）< bₙ
```

が成り立つ。ゆえに **最初の `b` より前に `a` が1個以上**あり、**隣接する2つの `b` の間に `a` が1個以上**ある。すなわち

```
w = a^{i₀} b a^{i₁} b ⋯ a^{i_{n−1}} b a^{i_n}      (i₀, …, i_{n−1} ≥ 1,  i_n ≥ 0)
```

**(⊇)** 逆にこの形の `w` に対し、各ブロック `a^{i_k}`（`k = 0, …, n−1`）の**最後の `a`** を `(ab)ⁿ` 側に指定すれば、指定された `a` と `b` は交互に並び `(ab)ⁿ` をなす。残りの `m = (Σ i_k) − n ≥ 0` 個の `a` が `aᵐ` 側であり、`w ∈ aᵐ ⧢ (ab)ⁿ`。

以上より求める正規表現は **`(aa*b)*a*`**。

*検算*: `aab ∈`（`i₀=2, i₁=0`）／`abab ∈`（`i₀=i₁=1, i₂=0`）／`aabb ∉`（2つの `b` の間に `a` がない）。

## 問題 A (3)

`A₁ = (Q₁, Σ, δ₁, q₀¹, F₁)`、`A₂ = (Q₂, Σ, δ₂, q₀², F₂)` とし、次の NFA `N` を構成する。

```
N = (Q₁ × Q₂,  Σ,  δ,  (q₀¹, q₀²),  F₁ × F₂)
δ((p, q), c) = { (δ₁(p, c), q),  (p, δ₂(q, c)) }      (c ∈ Σ)
```

**説明**: 入力語の各文字は `L₁` 側の語の文字か `L₂` 側の語の文字のいずれか一方である。`N` はどちら側の文字かを非決定的に選び、選んだ側のオートマトンのみを1歩進める。ε 遷移は不要で、状態数は `|Q₁||Q₂|`。

**正当性**: `|w|` に関する帰納法で次を示す。

> `(p′, q′) ∈ δ̂((p, q), w)` ⟺ ある `u, v` が存在して `w ∈ u ⧢ v`, `δ̂₁(p, u) = p′`, `δ̂₂(q, v) = q′`

`|w| = 0` のときは両辺とも `p′ = p ∧ q′ = q` と同値。`w = w′c` のとき、`N` の最後の遷移が第1成分を進めたか第2成分を進めたかは、`c` が `u` の最後の文字か `v` の最後の文字かに対応するので、帰納法の仮定から従う。

これを `(p, q) = (q₀¹, q₀²)` に適用し受理条件 `F₁ × F₂` と合わせると `L(N) = L₁ ⧢ L₂`。

## 問題 A (4) 命題1 → **真**

`L₁` の DFA を `A₁ = (Q₁, Σ, δ₁, q₀¹, F₁)`、`L₂` のプッシュダウンオートマトンを
`P₂ = (Q₂, Σ, Γ, δ₂, q₀², Z₀, F₂)`（最終状態受理）とする。次の PDA `P` を構成する。

```
P = (Q₁ × Q₂,  Σ,  Γ,  δ,  (q₀¹, q₀²),  Z₀,  F₁ × F₂)

δ((p,q), c, X) ∋ ((δ₁(p,c), q), X)                          … c を L₁ 側で消費（スタック不変）
δ((p,q), c, X) ⊇ { ((p,q′), γ) | (q′,γ) ∈ δ₂(q, c, X) }     … c を L₂ 側で消費
δ((p,q), ε, X) ⊇ { ((p,q′), γ) | (q′,γ) ∈ δ₂(q, ε, X) }     … P₂ の ε 動作
```

**説明**: (3) と同じ「各文字をどちら側に割り当てるか推測する」構成である。スタックは `P₂` のもの1本をそのまま使い、`L₁` 側で文字を消費するときはスタックに触れない。`A₁` は決定性有限オートマトンなのでスタックを必要としない点が本質で、**必要なスタックが1本で済む**。

入力を読み終えた時点で `A₁` の状態が `F₁`、`P₂` の状態が `F₂` にあれば受理する。(3) と同様の帰納法により `L(P) = L₁ ⧢ L₂`。よって `L₁ ⧢ L₂` は文脈自由。

（同じ構成で `A₂` も DFA にすれば (3) の「正規言語はシャッフルで閉じる」が得られる。）

## 問題 A (4) 命題2 → **偽**

**反例**

```
L₁ = { aⁿ bⁿ | n ≥ 0 }   （文脈自由: S → a S b | ε）
L₂ = { cᵐ dᵐ | m ≥ 0 }   （文脈自由: T → c T d | ε）
```

正規言語 `R = a*c*b*d*` との交わりを取ると

```
(L₁ ⧢ L₂) ∩ R = { aⁿ cᵐ bⁿ dᵐ | n, m ≥ 0 } =: M
```

**(⊇)** `aⁿcᵐbⁿdᵐ` において `a` と `b` は `aⁿbⁿ` の順序を、`c` と `d` は `cᵐdᵐ` の順序をそれぞれ保っているので、これは両者の混ぜ方の1つ。

**(⊆)** `w ∈ (L₁ ⧢ L₂) ∩ R` とすると `w = a^p c^q b^r d^s`。`L₂ ⊆ {c,d}*` なので `a, b` は必ず `L₁` 側、`c, d` は必ず `L₂` 側から来る。よって `L₁` 側の語は `a^p b^r ∈ L₁` すなわち `p = r`、`L₂` 側の語は `c^q d^s ∈ L₂` すなわち `q = s`。

**`M` が文脈自由でないこと（反復補題）**

`M` が文脈自由と仮定し反復長を `N` とする。`z = a^N c^N b^N d^N ∈ M` を取り `z = uvwxy`（`|vwx| ≤ N`, `|vx| ≥ 1`, `∀i. uvⁱwxⁱy ∈ M`）とする。

各ブロックの長さが `N` で `|vwx| ≤ N` だから、`vwx` は**隣接する高々2ブロック**にしか跨れない。特に `vx` が `a` と `b` の両方を含むことも、`c` と `d` の両方を含むこともない。`|vx| ≥ 1` より `vx` は少なくとも1文字を含むので、

- `vx` が `a` を含めば `i = 2` で `#a` が増えるが `#b` は不変 → `#a = #b` に反する
- `vx` が `b` を含めば同様に `#a = #b` に反する
- `vx` が `c` または `d` のみを含む場合も同様に `#c = #d` に反する

いずれの場合も矛盾。よって `M` は文脈自由でない。

文脈自由言語は正規言語との交わりで閉じているので、`L₁ ⧢ L₂` が文脈自由なら `M` も文脈自由でなければならない。矛盾。ゆえに **`L₁ ⧢ L₂` は文脈自由でない**。

## 問題 B (2)

**答: `CYCLE(a*b*) = a*b*a* + b*a*b*`**

**(⊆)** `aᵐbⁿ ∈ a*b*` を `uv` と分割する。切れ目が `a` のブロック内（`|u| = k ≤ m`）なら

```
u = a^k,  v = a^{m−k} bⁿ,  vu = a^{m−k} bⁿ a^k  ∈ a*b*a*
```

切れ目が `b` のブロック内（`|u| = m + j`, `0 ≤ j ≤ n`）なら

```
u = aᵐ b^j,  v = b^{n−j},  vu = b^{n−j} aᵐ b^j  ∈ b*a*b*
```

**(⊇)** `a^p bⁿ a^q` は `u = a^q, v = a^p bⁿ`（`uv = a^{q+p} bⁿ ∈ a*b*`）から得られる。
`b^p aᵐ b^q` は `u = aᵐ b^q, v = b^p`（`uv = aᵐ b^{q+p} ∈ a*b*`）から得られる。

## 問題 B (3)

**基本となる同値**

```
w ∈ CYCLE(L)
 ⟺ ∃ 分割 w = vu, ∃ r ∈ Q.  δ̂(q₀, u) = r  かつ  δ̂(r, v) ∈ F
```

（`uv ∈ L ⟺ δ̂(q₀, uv) = δ̂(δ̂(q₀,u), v) ∈ F` であり、`r := δ̂(q₀,u)` と置けばよい。）

入力は `v` が先に来るのに、`v` の読み取りを始める状態 `r` は `u` を読み終えるまで分からない。そこで **`r` を最初に非決定的に推測**し、フェーズ1で `v` を、フェーズ2で `u` を読む NFA を作る。

```
N = ( Q × Q × {1,2} ∪ {s₀},  Σ,  δ_N,  s₀,  F_N )

s₀      --ε-->  (r, r, 1)              （すべての r ∈ Q。r を推測しフェーズ1へ）
(p,r,1) --c-->  (δ(p,c), r, 1)         （v を読む）
(p,r,1) --ε-->  (q₀, r, 2)             （p ∈ F のときのみ。v を読み終えたと宣言）
(p,r,2) --c-->  (δ(p,c), r, 2)         （u を読む）

F_N = { (r, r, 2) | r ∈ Q }
```

**正当性**

- 受理計算があれば、入力は `v`（フェーズ1）と `u`（フェーズ2）に分かれ、`δ̂(r, v) ∈ F` かつ `δ̂(q₀, u) = r`。よって `δ̂(q₀, uv) = δ̂(r, v) ∈ F`、すなわち `uv ∈ L` で入力は `vu ∈ CYCLE(L)`。
- 逆に `w = vu`（`uv ∈ L`）なら `r := δ̂(q₀, u)` を推測すれば上の計算が存在する。

`v = ε` の場合は `r ∈ F` なら直ちに ε 遷移でフェーズ2へ移れる。`u = ε` の場合はフェーズ2で何も読まないので受理には `q₀ = r` が必要で、これは `δ̂(q₀, ε) = q₀ = r` と整合する。状態数は `2|Q|² + 1`。

## 問題 B (4)

長さ `n` の語 `z = z₁⋯zₙ` と `0 ≤ k < n` に対し、回転 `ρ_k(z) = z_{k+1}⋯zₙ z₁⋯z_k` を定める。定義より

```
CYCLE(M) = { ρ_k(z) | z ∈ M, 0 ≤ k < |z| }   （|z| = 0 のときは z 自身）
```

**回転の合成則**: `ρ_j(ρ_k(z)) = ρ_{(j+k) mod n}(z)`。
実際 `z′ = ρ_k(z)` とすると `z′_i = z_{((k+i−1) mod n)+1}` なので、`ρ_j(z′)` の第 `i` 文字は `z′_{((j+i−1) mod n)+1} = z_{((j+k+i−1) mod n)+1}` であり、これは `ρ_{(j+k) mod n}(z)` の第 `i` 文字に等しい。

**(⊇)** 任意の言語 `M` について `k = 0` を取れば `M ⊆ CYCLE(M)`。これを `M = CYCLE(L)` に適用して `CYCLE(L) ⊆ CYCLE(CYCLE(L))`。

**(⊆)** `w ∈ CYCLE(CYCLE(L))` とすると、ある `z ∈ CYCLE(L)` と `j` があって `w = ρ_j(z)`、さらにある `z′ ∈ L` と `k` があって `z = ρ_k(z′)`。合成則より `w = ρ_{(j+k) mod n}(z′)` であり `z′ ∈ L` だから `w ∈ CYCLE(L)`。

以上より `CYCLE(CYCLE(L)) = CYCLE(L)`。

（本質は「長さ `n` の語への回転全体が巡回群 `ℤ/nℤ` をなす」こと。）

## 問題 B (5) → **真**。ただし本問は出題として不適切

**結論**: 命題は真である。文脈自由言語が循環シフトで閉じることは **Oshiba (1972) / Maslov (1973) の定理**として知られる。

しかし、**この構成を試験時間内に書かせるのは無理がある**。以下に到達点と、どこで詰まるかを明示する。

### 到達できるところまで

`G = (V, Σ, P, S)` を `L` の Chomsky 標準形の文法とする。`w = uv ∈ L` の導出木で切れ目 `|u|` を含む最も低い節点を `B` とすると、`B → C D` で切れ目がちょうど `C` と `D` の境界に来るように取れる。このとき

```
S ⇒* x B y,   C ⇒* p,   D ⇒* q,   u = x p,   v = q y
```

と書けるので、回転後の語は `vu = q · y · x · p`。よって

```
CYCLE(L) = L  ∪  ⋃_{B → CD ∈ P}  L(D) · N(S, B) · L(C),
      ただし  N(A, B) = { y x | A ⇒* x B y }
```

この分解自体は正しく、`L(C)`, `L(D)` は文脈自由。**技術的な核心は `N(A,B)` が文脈自由であることの証明**である。

### どこで詰まるか

`N(A,B)` に素朴な規則を与えようとすると、`A → CD` で `B` が `C` 側にある場合

```
C ⇒* x B y₁  かつ  A ⇒* x B (y₁ · yield(D))
⟹  N(A,B) の語は  y₁ · yield(D) · x
```

となり、`N(C,B)` が生成する `y₁ x` の**「`y` と `x` の継ぎ目」に `yield(D)` を挿入**する必要がある。文脈自由文法の規則は生成された語の内部に挿入できないため、この形では書けない。`$` で継ぎ目を明示した `{ y $ x }` を考えても、`$` の直前・直後への挿入が必要となり、その置換を規則として閉じた形に書くには追加の工夫が要る（そこが上記定理の非自明な部分）。

したがって本問 (5) は、**答（真）だけ当てて部分点、という結果にしかならない**。

### 代替案 — 出題するならこちら

同じ「文法の手術」の技能を測りつつ、試験時間内に完答できる形に落とすなら次が適切である。

> **(5′)** 新しい記号 `$ ∉ Σ` を用いて `Mark(L) = { u $ v | uv ∈ L }` と定める。`L` が文脈自由ならば `Mark(L)` も文脈自由であることを、`Mark(L)` を生成する文脈自由文法の構成法を示すことによって証明せよ。

**(5′) の模範解答**

`G = (V, Σ, P, S)` を `L` の Chomsky 標準形の文法とする（`ε ∈ L` なら `S → ε` を許す）。各 `A ∈ V` に対して新しい非終端記号 `Ǎ` を導入し、

```
L(Ǎ) = { u $ s | A ⇒* u s }
```

となるようにする。規則は `G` の規則の形に応じて次のように定める。

| `G` の規則 | 追加する規則 | 根拠 |
|---|---|---|
| `A → a` | `Ǎ → $ a \| a $` | `A ⇒* a` の切り方は `(ε,a)` と `(a,ε)` の2通り |
| `A → B C` | `Ǎ → B̌ C \| B Č` | 切れ目が `w_B` の中なら `u $ s w_C`（`B̌` の後ろに `C` を連接）、`w_C` の中なら `w_B u′ $ s`（`B` の後ろに `Č` を連接） |
| `S → ε` | `Š → $` | 空語の切り方は1通り |

開始記号を `Š` とすれば `L(Š) = Mark(L)` となる。

**正当性**（導出の長さに関する帰納法）: `A ⇒* w` かつ `w = u s` なる分割に対し、`A → BC` を最初に使ったとすると `w = w_B w_C` で切れ目は `w_B` 内か `w_C` 内のいずれか。前者なら `w_B = u s′` と書けて `s = s′ w_C`、帰納法の仮定より `B̌ ⇒* u $ s′` だから `Ǎ → B̌ C ⇒* u $ s′ w_C = u $ s`。後者も同様。逆向きも同じ対応で示せる。

（なお `Mark` は「任意の位置に一度だけ `$` を出力する有限変換」であり、文脈自由言語が有理変換で閉じることからも従う。上の文法構成はそれを具体化したもの。）
