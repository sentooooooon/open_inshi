# 予想問題（形式言語）— シャッフル／循環シフト

`utokyo_trend_and_forecast.md` の予想に基づく**自作の模擬問題**。fy2020・fy2022・fy2024・fy2025 の問題1（形式言語）と同じテンプレートで作成した。

> **(1)** 具体例の手計算 → **(2)** 正規表現で表す → **(3)** DFA から NFA を構成 → **(4)** 文脈自由言語の閉包性の真偽

これらは過去問ではなく**私が作成した予想問題**である。実際の出題を保証するものではない。

# 問題 A — シャッフル（interleaving）

`Σ = {a, b, c, d}` とする。語 `u, v ∈ Σ*` に対して、**シャッフル** `u ⧢ v ⊆ Σ*` を以下のように帰納的に定義する。

```
ε ⧢ v = {v},   u ⧢ ε = {u},
(xu) ⧢ (yv) = x·(u ⧢ (yv))  ∪  y·((xu) ⧢ v)      (x, y ∈ Σ)
```

すなわち `u ⧢ v` は、`u` と `v` のそれぞれの文字の順序を保ったまま交互に混ぜて得られる語の集合を表す。
例えば `ab ⧢ c = {cab, acb, abc}` である。

さらに、言語 `L₁, L₂ ⊆ Σ*` に対して

```
L₁ ⧢ L₂ = ⋃_{u∈L₁, v∈L₂} (u ⧢ v)
```

と定義する。以下の問いに答えよ。

**(1)** `ab ⧢ ba` を求めよ。

**(2)** `L₁` を正規表現 `a*` で表される言語、`L₂` を正規表現 `(ab)*` で表される言語とする。`L₁ ⧢ L₂` を正規表現で表せ。

**(3)** `L₁, L₂` がそれぞれ決定性有限オートマトン `A₁, A₂` によって受理される `Σ` 上の言語であるとする。`L₁ ⧢ L₂` を受理する非決定性有限オートマトンを `A₁, A₂` から構成する方法を、簡単な説明とともに示せ。

**(4)** 以下の2つの命題について、それぞれ真であるか否かを答えよ。真であればその証明の概略を、そうでなければ簡単な説明とともに反例を示せ。

> **命題 1**: `Σ` 上のすべての言語 `L₁, L₂ ⊆ Σ*` について、`L₁` が正規言語かつ `L₂` が文脈自由言語ならば、`L₁ ⧢ L₂` は文脈自由言語である。
>
> **命題 2**: `Σ` 上のすべての言語 `L₁, L₂ ⊆ Σ*` について、`L₁` と `L₂` がともに文脈自由言語ならば、`L₁ ⧢ L₂` は文脈自由言語である。

# 問題 B — 循環シフト（cyclic shift）

`Σ = {a, b}` とする。言語 `L ⊆ Σ*` に対して、**循環シフト** `CYCLE(L) ⊆ Σ*` を以下によって定義する。

```
CYCLE(L) = { vu  |  u, v ∈ Σ*,  uv ∈ L }
```

すなわち `CYCLE(L)` は、`L` の語を任意の位置で2つに切り、前半と後半を入れ替えて得られる語全体からなる。
例えば `CYCLE({abc}) = {abc, bca, cab}` である（`Σ` に `c` が含まれる場合）。

以下の問いに答えよ。

**(1)** `CYCLE({abb, ba})` を求めよ。

**(2)** `L` を正規表現 `a*b*` で表される言語とする。`CYCLE(L)` を正規表現で表せ。

**(3)** `L` が決定性有限オートマトン `A = (Q, Σ, δ, q₀, F)` によって受理される言語であるとする。`CYCLE(L)` を受理する非決定性有限オートマトンを `A` から構成する方法を、簡単な説明とともに示せ。ε 遷移を用いてもよい。

**(4)** 任意の言語 `L ⊆ Σ*` について `CYCLE(CYCLE(L)) = CYCLE(L)` が成り立つことを示せ。

**(5)** 以下の命題が真であるか否かを答えよ。真であればその証明の概略（`CYCLE(L)` を生成する文脈自由文法の構成法を簡単な説明とともに示せばよい）を、そうでなければ簡単な説明とともに反例を示せ。

> **命題**: `Σ` 上のすべての言語 `L ⊆ Σ*` について、`L` が文脈自由言語ならば `CYCLE(L)` も文脈自由言語である。

# 解答例

## 問題 A

### (1)

`u = ab`（文字 `a₁ b₂`）と `v = ba`（文字 `b₁ a₂`）を混ぜる。長さ4の語のうち `u` の文字が入る2箇所の選び方は `C(4,2) = 6` 通り。

| `u` の位置 | 結果 |
|---|---|
| {1,2} | `abba` |
| {1,3} | `abba` |
| {1,4} | `abab` |
| {2,3} | `baba` |
| {2,4} | `baab` |
| {3,4} | `baab` |

**`ab ⧢ ba = {abab, abba, baab, baba}`**

### (2)

`a^m` と `(ab)^n` を混ぜた語 `w` を考える。`w` 中の `b` はすべて `(ab)^n` 側から来るので `#b(w) = n`。
また `(ab)^n` の各 `b` は、その直前に「`(ab)^n` 側の `a`」を1つ持たなければならない。したがって

- 最初の `b` の前に `a` が1個以上ある
- 隣り合う2つの `b` の間に `a` が1個以上ある

が必要十分。逆にこの条件を満たせば、各ブロックの最後の `a` を `(ab)^n` 側に割り当てれば実現できる（残りの `a` は `a^m` 側）。

よって `w = a^{i₀} b a^{i₁} b ⋯ a^{i_{n−1}} b a^{i_n}`（`i₀,…,i_{n−1} ≥ 1`, `i_n ≥ 0`）の形。

**`L₁ ⧢ L₂ = (aa*b)*a*`**　（`= (a⁺b)*a*`）

検算: `aab ∈`（`i₀=2, i₁=0`）／`abab ∈`（`i₀=i₁=1, i₂=0`）／`aabb ∉`（2つの `b` の間に `a` がない）。

### (3)

`A₁ = (Q₁, Σ, δ₁, q₀¹, F₁)`, `A₂ = (Q₂, Σ, δ₂, q₀², F₂)` とする。次の NFA `N` を構成する。

- 状態集合: `Q₁ × Q₂`
- 初期状態: `(q₀¹, q₀²)`
- 受理状態集合: `F₁ × F₂`
- 遷移: 各 `c ∈ Σ` について
  ```
  δ((p, q), c) = { (δ₁(p, c), q),  (p, δ₂(q, c)) }
  ```

**説明**: 入力語の各文字は `L₁` 側か `L₂` 側のどちらか一方に属する。NFA はどちら側の文字かを非決定的に推測し、対応するオートマトンだけを1歩進める。入力を読み終えた時点で両方が受理状態にあれば、読んだ語は `L₁` の語と `L₂` の語のシャッフルである。ε 遷移は不要。

### (4)

#### 命題 1 → **真**

`A₁` を `L₁` の DFA、`P₂` を `L₂` のプッシュダウンオートマトンとする。(3) と同じ発想で、状態を `Q₁ × Q_{P₂}`、スタックを `P₂` のものとする PDA を作る。入力文字 `c` を読むとき、非決定的に

- `A₁` 側で消費する（`A₁` の状態のみ遷移。スタックは触らない）
- `P₂` 側で消費する（`P₂` の遷移をそのまま適用。スタック操作を伴う）

のどちらかを選ぶ。`P₂` の ε 遷移（入力を読まないスタック操作）はそのまま許す。受理条件は `A₁` の状態が `F₁` に属し、かつ `P₂` が受理状態であること。

スタックは `P₂` のもの1本で足りるので、これは正しい PDA であり、`L₁ ⧢ L₂` は文脈自由。

#### 命題 2 → **偽**

反例:
```
L₁ = { aⁿ bⁿ | n ≥ 0 }      （文脈自由）
L₂ = { cᵐ dᵐ | m ≥ 0 }      （文脈自由）
```

`L₁ ⧢ L₂` を正規言語 `a*c*b*d*` と交わすと、

```
(L₁ ⧢ L₂) ∩ a*c*b*d* = { aⁿ cᵐ bⁿ dᵐ | n, m ≥ 0 }
```

**（⊇）** `aⁿ cᵐ bⁿ dᵐ` は `aⁿbⁿ` と `cᵐdᵐ` の順序を保った混ぜ方になっている。
**（⊆）** `a*c*b*d*` の語で `L₁ ⧢ L₂` に属するものは、`a` と `b` が `L₁` 側、`c` と `d` が `L₂` 側から来るので `#a = #b`, `#c = #d`。

`{ aⁿcᵐbⁿdᵐ }` は文脈自由でない。反復補題で `z = a^N c^N b^N d^N` を取ると、`|vwx| ≤ N` より `vwx` は隣接する高々2ブロックにしか跨れないので、`i = 2` に膨らませると `#a = #b` か `#c = #d` の一方が必ず破れる。

文脈自由言語は正規言語との交わりで閉じているので、`L₁ ⧢ L₂` は文脈自由でない。

## 問題 B

### (1)

- `abb` の巡回: `abb`（切り位置0,3）, `bba`（1）, `bab`（2）→ `{abb, bba, bab}`
- `ba` の巡回: `ba`（0,2）, `ab`（1）→ `{ba, ab}`

**`CYCLE({abb, ba}) = {ab, ba, abb, bab, bba}`**

### (2)

`aᵐbⁿ` を左に `k` だけ回すと

- `k ≤ m` のとき: `a^{m−k} bⁿ a^k` → `a*b*a*` の形
- `k = m + j`（`0 ≤ j ≤ n`）のとき: `b^{n−j} aᵐ b^j` → `b*a*b*` の形

逆に `a^p bⁿ a^q` は `a^{p+q} bⁿ` から、`b^p aᵐ b^q` は `aᵐ b^{p+q}` から得られる。

**`CYCLE(a*b*) = a*b*a* + b*a*b*`**

### (3)

`w ∈ CYCLE(L)` ⟺ `w = vu` と分割でき、ある状態 `r ∈ Q` が存在して
`δ(q₀, u) = r` かつ `δ(r, v) ∈ F` が成り立つ。

そこで **`r` を最初に推測する** NFA `N` を作る。

- 状態集合: `Q × Q × {1, 2}`（第2成分が推測した `r`、第3成分がフェーズ）
- 初期状態: `{ (r, r, 1) | r ∈ Q }`（各 `r` を推測し、`r` から `v` の読み取りを始める）
- 遷移:
  ```
  (p, r, 1) --c--> (δ(p, c), r, 1)      … v を読む
  (p, r, 1) --ε--> (q₀, r, 2)   （p ∈ F のときのみ）  … v を読み終えたと宣言
  (p, r, 2) --c--> (δ(p, c), r, 2)      … u を読む
  ```
- 受理状態: `{ (r, r, 2) | r ∈ Q }`

**説明**: フェーズ1で「状態 `r` から始めて `v` を読み `F` に到達する」ことを確認し、フェーズ2で「`q₀` から `u` を読んで `r` に戻る」ことを確認する。両方成立すれば `δ(q₀, uv) = δ(r, v) ∈ F`、すなわち `uv ∈ L` かつ入力は `vu`。状態数は `2|Q|²`。

### (4)

`w ∈ CYCLE(CYCLE(L))` とする。ある `x, y` があって `w = yx` かつ `xy ∈ CYCLE(L)`。
さらにある `u, v` があって `xy = vu` かつ `uv ∈ L`。

長さで場合分けする。`|v| ≥ |x|` のとき `v = x s` と書けて `y = s u`、よって
`w = y x = s u x` であり `(u x)(s) = u (x s) = u v ∈ L`。すなわち `w ∈ CYCLE(L)`。
`|v| < |x|` のときも同様に `x = v t` と書けて `u = t y`、`w = y v t` であり `(v t)(y) = v (t y) = v u = xy` … と辿ると `uv ∈ L` から `w ∈ CYCLE(L)` が従う。

（本質的には「巡回シフトの合成は巡回シフト」＝長さ `n` の語に対する巡回置換全体が群 `ℤ/nℤ` をなすこと。）

逆の包含 `CYCLE(L) ⊆ CYCLE(CYCLE(L))` は `u = ε` と取れば明らか。よって等号。

### (5) → **真**

新しい記号 `$ ∉ Σ` を導入し、文脈自由文法 `G = (V, Σ, P, S)` の各非終端記号 `A` に対して

```
M_A = { s $ u  |  A ⇒* u s,  u, s ∈ Σ* } ⊆ (Σ ∪ {$})*
```

を考える。`M_A` は `A` が導出する語を任意の位置で切り、後半・`$`・前半の順に並べた語の集合である。`M_A` を生成する規則を、`G` を Chomsky 標準形に変換した上で `A` の規則ごとに与える。

- **`A → a`**（終端記号）: 切り位置は2通りなので
  `M_A → a $ | $ a`
- **`A → ε`**: `M_A → $`
- **`A → B C`**: `A ⇒* w_B w_C` の切り位置が `w_B` の中か `w_C` の中かで分ける。
  - `w_B = u s` で切る場合、回した語は `s w_C u`、すなわち対 `(u, s w_C)`。これは `M_B` の生成する `s $ u` の `$` を `C $` に置き換えたものに等しい。
  - `w_C = u′ s` で切る場合、回した語は `s w_B u′`、すなわち対 `(w_B u′, s)`。これは `M_C` の生成する `s $ u′` の `$` を `$ B` に置き換えたものに等しい。

  `M_B` の生成する語には `$` がちょうど1個しか現れないので、**`M_B` の文法の複製を作り、規則中に現れる終端記号 `$` を記号列 `C $` に置き換える**（`M_C` 側も同様に `$ B` に置き換える）という文法変形が可能である。その複製の開始記号をそれぞれ `M_B^{(C)}`, `M_C^{(B)}` として
  `M_A → M_B^{(C)} | M_C^{(B)}`

以上で `M_S` を生成する文脈自由文法が得られる。最後に `$` を消去する準同型 `h`（`h($) = ε`, `h(x) = x` for `x ∈ Σ`）を施すと

```
CYCLE(L) = h(M_S)
```

文脈自由言語は準同型像で閉じているので、`CYCLE(L)` は文脈自由である。

（この結果は Oshiba (1972) / Maslov (1973) による古典的定理。試験では「`$` で切れ目を明示した補助言語 `M_A` を作り、最後に準同型で `$` を消す」という骨格が書けていれば十分と思われる。）
