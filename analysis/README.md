# analysis

収録済みの過去問を読んで書いた**傾向分析・対策資料**。

**これは過去問本体ではありません。** 大学が公開した解答・解答例・出題の意図の転載でもありません。過去問を読んだ上での二次的な分析であり、**推論を含み、無保証**です。方針は [ルート README の「`analysis/` の方針」](../README.md#analysis-の方針) を参照してください。

**調査範囲**: CS は fy2014〜fy2025 の夏（fy2019 以前は専門科目 I・II の全題）＋ fy2014冬〜fy2021冬 の**計24回分**。数学は fy2003〜fy2025 の全題（fy2020 は筆記未実施のため欠番）＋ fy2001・fy2002 の確率枠。未読は数学 fy2001 の全問と fy2002・fy2003 の一部（計およそ9題）のみ。

### 3行で

1. **この研究科に「未出の穴」はほぼ存在しない。** 6〜8年の窓で狙い目に見えた題材（動的計画法・シャッフル・マルコフ連鎖・SVD・順序統計量など）は、24回分・25年分に広げるとほぼ全部既出だった。
2. **信頼できるのは「枠」であって「題材」。** 数学の3枠固定（19年）、CS 問題1 の形式言語テンプレート、アーキが毎年1題 — この3点だけが例外なく続いている。
3. **冬入試は夏の予告編。** fy2025 問題3(1) は fy2020冬 問題2(1) とほぼ同一問題。冬入試8回分が夏の対策として最も費用対効果が高い。

詳しくは [`utokyo_trend_and_forecast.md`](./utokyo_trend_and_forecast.md) の第0章と第6章。
